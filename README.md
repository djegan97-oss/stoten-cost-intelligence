# Stoten Cost Intelligence

Interactive construction cost intelligence platform — v2 prototype.

## What this is

A fully functional browser-based demo built in May 2026 as a working prototype for Stoten's construction management team. All data is dummy/illustrative.

## Dashboards

- **Portfolio View** — 10-project national overview with budget vs. actual
- **Regional Compare** — Side-by-side project comparison, normalized for SF, clear height, and site premiums
- **Trade Pricing** — Commodity pricing trends (dock doors, tilt panel, structural steel, site work) by region and quarter

## Data Sections

- **Cost Database** — Full cost breakdown by 10 trade categories per project
- **Project History** — Card view of all projects, clickable to project detail
- **Data Ingest** — Illustration of future upload workflow (not yet connected to live DB)
- **Bid Compare** — GC bid leveling for 3 projects (Katherines Crossing, Wolf Rd, Nashville)
- **Data Foundation** — Schema and methodology documentation

## Intelligence (illustration only)

- **AI Query** — Demo of natural language query interface (pre-seeded responses, no live LLM)
- **New Estimate** — Demo estimate generator (not connected to live data)

## Status

This is a **demo prototype** — no backend, no database, no live connections. Intended for UX/feature discussion with the construction management team before an enterprise rebuild.
